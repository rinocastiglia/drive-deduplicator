Informativa sulla Privacy (Privacy Policy)

Ultimo aggiornamento: 16 Ottobre 2026 | Applicazione: Google Drive Deduplicator Pro | Sviluppatore: Rino Castiglia

La presente Informativa sulla Privacy descrive come Google Drive Deduplicator Pro ("l'Applicazione", "il Software"), sviluppato da Rino Castiglia, gestisce le informazioni e i dati degli utenti in relazione all'accesso alle API di Google Drive.

Dichiarazione di conformità alle norme di Google sui dati utente:
L'uso e il trasferimento a qualsiasi altra app da parte di Google Drive Deduplicator Pro delle informazioni ricevute dalle API di Google sono conformi alle Norme sui dati utente dei servizi API di Google, inclusi i requisiti di Uso limitato (Limited Use Requirements).

1. Natura dell'Applicazione (Software 100% Locale)

Google Drive Deduplicator Pro è un software standalone per ambiente Windows che viene eseguito esclusivamente in locale sul computer dell'utente. Il software non dispone di server backend proprietari o cloud esterni. Nessun dato, file, credenziale o metadato viene mai inviato o salvato su server terzi o controllati dallo sviluppatore.

2. Dati Google Raccolti e Autorizzazioni Utilizzate

L'Applicazione richiede l'autorizzazione di accesso tramite protocollo standard OAuth 2.0 alle API ufficiali di Google Drive (ambito: https://www.googleapis.com/auth/drive). Nello specifico, il software legge esclusivamente:

  • Metadati dei file: Nome del file, dimensione in byte, hash crittografico MD5 calcolato da Google, data di modifica, ID del file e ID della cartella genitore.
  • Informazioni di base sulla quota: Spazio totale e spazio utilizzato nell'account Google Drive per mostrare il grafico di archiviazione all'utente.
  • Email e nome visualizzato: Esclusivamente per mostrare all'utente l'account attualmente collegato nella barra superiore dell'interfaccia.
Importante (Zero Download dei Contenuti): L'applicazione NON scarica, non legge e non analizza mai il contenuto interno o il corpo dei tuoi documenti, immagini o archivi. Il confronto per identificare copie identiche avviene matematicamente tramite l'hash crittografico MD5 fornito direttamente dai server di Google.

3. Finalità dell'Uso dei Dati

I metadati letti vengono utilizzati per le seguenti finalità:

  • Raggruppare i file identici al 100% (stessa dimensione in byte e stesso hash MD5).
  • Identificare la copia originale più vecchia, che rimane intatta nella sua cartella.
  • Spostare le copie duplicate superflue nella cartella speciale _DUPLICATI_DA_REVISIONARE creata direttamente nella root del Google Drive dell'utente, mediante aggiornamento dei puntatori di cartella (chiamata API files.update con addParents e removeParents).

4. Politica di Non Cancellazione e Controllo Utente

L'Applicazione adotta una rigorosa politica di zero cancellazioni automatiche: il software non invia mai comandi di cancellazione permanente (files.delete) né di invio al cestino. I file duplicati vengono esclusivamente isolati nella cartella di revisione. Spetta sempre all'utente la decisione finale se ed eliminare i file dal proprio account Google.

5. Conservazione e Sicurezza dei Dati

  • Token di accesso OAuth: Vengono memorizzati esclusivamente in locale sul personal computer dell'utente nel file token.json con crittografia del sistema operativo. L'utente può disconnettere o revocare l'accesso in qualsiasi momento con il tasto "Cambia Utente" o tramite la pagina delle Autorizzazioni dell'account Google.
  • Indice SQLite: L'indice locale dei metadati (drive_index.db) risiede unicamente sul disco fisso dell'utente e può essere azzerato in qualsiasi momento tramite il pulsante "Reset Indice Locale".

6. Nessuna Condivisione o Vendita di Dati

Lo sviluppatore garantisce che:

  • Nessun dato ricavato dalle API di Google viene venduto o concesso in licenza a terzi.
  • Nessun dato viene utilizzato per scopi pubblicitari o di profilazione.
  • Nessun dato viene impiegato per l'addestramento di modelli di intelligenza artificiale o machine learning generalizzati.
  • Nessun dato viene condiviso con terze parti, salvo richiesta obbligatoria per legge.

7. Diritti dell'Utente

Gli utenti hanno il pieno controllo sui propri dati in qualsiasi momento:

  • Possono cancellare l'indice locale e i file di registro direttamente dall'applicazione.
  • Possono revocare le autorizzazioni concesse all'applicazione in qualsiasi momento direttamente dalle impostazioni di sicurezza del proprio account Google: https://myaccount.google.com/permissions.
