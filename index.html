Caratteristiche Principali

Progettato per gestire archivi enormi con precisione matematica e massima velocità.

⚡ Zero Download Server-Side

Non scarica i tuoi file sul PC. Interroga le API ufficiali Google Drive v3 leggendo l'hash MD5 generato direttamente dai datacenter di Google.

🛡️ 100% Zero Cancellazioni

Il software non cancella mai alcun file. Le copie duplicate vengono solo spostate nella cartella speciale _DUPLICATI_DA_REVISIONARE.

📦 Area di Revisione Sicura

Gli originali più vecchi rimangono intatti nelle loro cartelle. Sarai tu a esaminare i duplicati nel browser e a decidere quando eliminarli per liberare spazio.

🌐 Multilingua Dinamico (5 Lingue)

Interfaccia moderna e intuitiva disponibile in Italiano, English, Español, Français e Deutsch, con cambio lingua istantaneo in meno di 15 ms.

📊 Grafico Quota in Tempo Reale

Grafico proporzionale che visualizza lo spazio occupato dai duplicati, dai file utili, da Gmail/Foto e calcola la stima esatta dello spazio che recupererai.

⏸️ Pausa e Ripresa Istantanea

Puoi interrompere la scansione o lo spostamento in qualsiasi momento. Lo stato viene salvato nel database locale e riparte all'istante dall'ultimo file.

🛡️ Filosofia di Sicurezza: Nessuna Eliminazione Automatica

  • ✅ Gli originali non si toccano: I file originali più vecchi rimangono rigorosamente intatti nelle loro posizioni di origine.
  • ✅ Nessuna cancellazione arbitraria: Il software effettua solo operazioni di spostamento. Non chiama mai le API di cancellazione di Google.
  • ✅ Controllo totale all'utente: Un comodo tasto nell'app apre la cartella di revisione su Google Drive nel browser, lasciando a te la decisione finale di eliminare i file quando vuoi.
  • ✅ Esclusione automatica: La cartella di revisione viene saltata dalle future scansioni per non creare falsi allarmi o duplicazioni.
  • ✅ Privacy al 100% locale: L'eseguibile gira interamente sul tuo PC locale. Nessun file, credenziale o dato viene trasmesso a server terzi o esterni.
